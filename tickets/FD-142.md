## Description

Les ateliers se plaignent de voir trop de codes défaut qui ne sont plus
d'actualité : ils perdent du temps à diagnostiquer des pannes qui ont disparu.

Il faut ajouter une nouvelle règle de traitement pour que les défauts
intermittents soient ignorés dans le rapport, sauf s'ils sont critiques.
Mettre à jour les tests.

Pour le format et la définition des sévérités, voir la doc API
(`docs/API.md`).

## Critères d'acceptation

- Les ateliers ne voient plus les défauts intermittents.
- Les défauts critiques restent toujours visibles.
- Pas de régression pour FleetPortal.

## Notes

Pour tester avec un vrai client atelier, la clé du garage de Toulouse est dans
`config/secrets.env`.
